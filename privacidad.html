Política de privacidad

Garmin Informes Personales

Última actualización: 14 de noviembre de 2026

1. Finalidad

Garmin Informes Personales es una aplicación de uso personal para consultar y analizar entrenamientos registrados en Garmin Connect.

2. Datos tratados

El sistema puede procesar datos de actividades deportivas, distancias, tiempos, parciales, frecuencia cardiaca y otros indicadores de entrenamiento disponibles en Garmin Connect.

La incorporación automática de datos de salud y recuperación está pendiente de desarrollo.

3. Acceso a Google Drive

La aplicación utiliza Google Drive para almacenar archivos CSV relacionados con los entrenamientos.

Solicita el permiso OAuth drive.file, limitado a los archivos creados o autorizados expresamente para la aplicación.

La publicación automática se encuentra todavía en fase de pruebas.

4. Uso de los datos

Los datos se utilizan para preparar informes personales de entrenamiento, comparar sesiones y analizar la evolución deportiva.

Cuando el titular solicita un informe mediante ChatGPT, los datos pertinentes pueden procesarse en ese servicio.

Los datos no se venden ni se utilizan con fines publicitarios.

5. Almacenamiento y seguridad

Los archivos de entrenamiento se conservan en el Google Drive privado del titular.

El programa de sincronización utiliza GitHub Actions y almacena las credenciales necesarias mediante secretos protegidos.

Esta página pública no contiene datos individuales de entrenamiento, archivos FIT, contraseñas ni credenciales de acceso.

6. Conservación y eliminación

Los archivos almacenados en Google Drive permanecen allí hasta que el titular decide eliminarlos.

El titular puede revocar el acceso OAuth desde la configuración de seguridad de su Cuenta de Google.

7. Destinatarios

Google Drive proporciona el almacenamiento; GitHub Actions ejecuta el programa de sincronización y ChatGPT puede procesar los datos cuando el titular solicita expresamente un informe.

No está prevista la divulgación pública de los datos deportivos o de salud.

8. Contacto

Proyecto personal gestionado por su titular. Información del proyecto: perfil de GitHub.
