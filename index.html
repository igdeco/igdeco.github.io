Garmin Informes Personales

Aplicación privada de uso personal para el análisis de entrenamientos, actividad física y recuperación.

Funcionamiento

El sistema permite consultar datos de Garmin Connect y preparar informes de entrenamiento utilizando información almacenada en Google Drive.

La aplicación se encuentra en fase de desarrollo y pruebas.

Privacidad

Esta web es exclusivamente informativa. No publica entrenamientos, datos de salud ni credenciales de acceso.
